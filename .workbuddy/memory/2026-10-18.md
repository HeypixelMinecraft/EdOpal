# 2026-10-18

## ClickGUI 新增 Naven 模式（迁移自 NavenAlpha-NoAuth）

- `ClickGUIModule` 增加 `ModeProperty<ClickGUIMode> "Mode"`（枚举 `Opal` / `Naven`），并置于属性列表首位；`onEnable`/`onDisable`/`RenderBloomEvent` 按模式分派到 `DropdownClickGUI` 或 `NavenClickGUI`；`addUpdateListener` 支持 GUI 打开时热切换。
- 新增 `wtf.opal.client.screen.click.ClickGUIMode` 枚举（常量名即显示名）。
- 新增 `wtf.opal.client.screen.click.naven.NavenClickGUI`（约 800 行）：把 Naven 的 `ClickGUI`（Mojang 映射、自有 Value/RenderUtils/SmoothAnimationTimer 体系）重写为 Opal 体系：
  - `Value` → `Property`（Boolean / Number / Mode，另有 Color、String 只读展示；GroupProperty 与 MultipleBooleanProperty 递归展开）。
  - `RenderUtils.drawRoundedRect/fill/isHovering` → `NVGRenderer.roundedRect/rect/scissor` + `HoverUtility`。
  - `SmoothAnimationTimer` → 内部类 `SmoothAnimation`（指数平滑，帧率无关）。
  - `Fonts.miSans`（基准 32 × scale）→ `productsans-*`，字号按 32×scale 换算；图标用 `materialicons-outlined`，分类图标直接复用 `ModuleCategory.getIcon()`。
  - 保留 Naven 交互：左键开关模块、右键展开属性、中键绑定、标题栏拖动、右下角缩放（最小 400×250）、模块/属性双区独立滚动与滚动条、绑定遮罩。
  - 折叠态高度改为 168，避免 5 个分类溢出背景面板。
  - 支持客户端主题色（`ColorUtility.getClientTheme()`）替代 Naven 固定蓝色。

## 构建环境注意

- 本机 JDK 默认 25，本项目需 JDK 21（`C:/Program Files/Java/latest/jdk-21`）。
- Gradle wrapper 的 8.14.2 发行包需手动放入 `~/.gradle/wrapper/dists/gradle-8.14.2-bin/<hash>/`；JDK 联网走 `-Djavax.net.ssl.trustStoreType=Windows-ROOT -Djavax.net.ssl.trustStore=NONE` 才能解析依赖（本机有 TLS 拦截）。
- 验证命令：`JAVA_HOME="...jdk-21" ./gradlew compileClientJava --offline` → BUILD SUCCESSFUL。
